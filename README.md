
# floaritay 个人博客与学习笔记

欢迎访问 floaritay 的个人博客主页！本项目集成了学习笔记、项目实践、技术栈与技能展示，支持模块化切换与高效检索。

## 页面结构与功能

- **模块化导航**：页面顶部可切换“介绍”、“项目”、“笔记”三大模块，体验简洁直观。
- **项目展示**：精选个人重要项目，配有简介与直达 GitHub 仓库按钮。
- **技能与工具**：以卡片形式分组展示编程语言、开发工具、机器学习、深度学习、计算机视觉、机器人、数据分析等技能。
- **学习笔记索引**：自动收录 docs 目录下所有 HTML 笔记，支持分类筛选与关键词搜索。
- **回到顶部按钮**：页面右下角悬浮，便于快速返回顶部。

## 主要内容分类

- **基础工具**：Conda, CUDA, Docker, Git, Linux, Markdown, VS Code, Ollama 等
- **Python 编程**：高级语法、正则表达式、GUI、tkinter 等
- **数据分析**：Numpy, Pandas, Matplotlib，实际案例如学生成绩分析、电影评分系统
- **机器学习**：Scikit-learn, 决策树、SVM、贝叶斯、神经网络等
- **深度学习**：PyTorch, TensorFlow, YOLO, OpenCV 等
- **计算机视觉**：图像处理、特征提取、分割、复原等
- **自然语言处理**：NLP 相关方法与实践
- **机器人与 ROS**：ROS2, Gazebo, URDF, 机器人仿真与建模
- **智能代理**：Agent, LangChain
- **爬虫与数据采集**：requests, BeautifulSoup, Scrapy 等
- **智能决策与规划**：VRP 等优化算法
- **MatLab**：MatLab 使用与数学建模
- **其他**：FastAPI, SQL 等

## 快速使用指南

1. 打开 docs/index.html 即可访问主页，支持本地或 GitHub Pages 部署。
2. 顶部切换栏可浏览“介绍”、“项目”、“笔记”三大模块。
3. 项目区点击“查看仓库”按钮直达 GitHub。
4. 笔记区支持分类筛选与关键词搜索，便于快速定位内容。
5. 右下角“回到顶部”按钮提升浏览体验。

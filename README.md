# 我的学习笔记

欢迎来到我的学习笔记集合！这个网站包含了我学习Python、数据分析、机器学习、深度学习、计算机视觉、自然语言处理、机器人技术等各个领域的笔记和代码示例。

## 内容概览

本书分为以下几个主要部分：

- **基础工具**: Conda, CUDA, Docker, Git, Linux, Markdown, Ollama, VS Code 等开发工具的使用。
- **Python编程**: Python 高级话题、正则表达式、GUI 编程等。
- **数据分析**: NumPy, Pandas, Matplotlib 等库的使用，以及实际项目如学生成绩分析和电影评分系统。
- **机器学习**: Scikit-learn, 决策树、支持向量机、贝叶斯算法、神经网络等。
- **计算机视觉**: OpenCV, 图像处理算法、特征提取等。
- **深度学习**: TensorFlow, PyTorch 等框架。
- **自然语言处理**: NLP 相关笔记。
- **机器人与ROS**: ROS2 入门、建模仿真、机器人学。
- **智能代理**: Agent 和 LangChain。
- **爬虫**: 各种爬虫技术，包括 Scrapy。
- **智能决策与规划**: VRP 等优化问题。
- **MatLab**: MatLab 使用和数学建模。
- **其他**: FastAPI, SQL 等。

## 如何使用

- 点击左侧导航栏浏览不同章节。
- 每个章节包含代码示例和解释。
- 代码块可以直接在浏览器中查看，但不执行（为了展示目的）。

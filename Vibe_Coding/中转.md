# 一、购买账号

## 卡密
一般卡密格式如下：
```txt
{"version": 1, "db_id": 26468, "platform": "chatgpt", "email": "shira.farah@outlook.com", "password": "i1xG@rWfrhh17npC", "login_identity": "shira.farah@outlook.com", "phone": "+573215913125", "access_token": 。。。。省略。。 mailbox_url": "http://ms.outlook007.cc/api/open/email/latest?api_key=0lQpMJYvnN3gWOd6wARKLlzasdjajkdjkx&pt=VJjH5W&email=shira.farah@outlook.com"}

Gpt账户：shira.farah@outlook.com

邮箱验证码接码链接：http://ms.outlook007.cc/api/open/email/latest?api_key=0lQpMJYvnN3gWOd6wARKLlzasdjajkdjkx&pt=VJjH5W&email=shira.farah@outlook.com
```

### 1. 网页登录
在网页登录，进入`邮箱验证码接码链接`拿到验证码

### 2. 中转平台导入（CPA / SUB / SUB2API）
复制或者导入卡密到转换链接，先转标准化JSON，再转为对应中转平台格式。然后下载。

### CPA
选择上传，找到解压后的文件夹，全选里面的文件，上传。

### SUB
账号管理-更多操作-导入

## 过期
到期可购买复活产品（如 free 复活）。

# 二、中转站

## 注册与兑换

1. 打开中转站
2. 新用户注册，填入邮箱，用验证码验证
3. 登录后，前往额度购买页兑换额度
4. 登录后创建密钥，记录地址和密钥

# 四、CPA / SUB 授权教程

## CPA 授权

1. 选择OAuth登录，复制链接打开无痕浏览器
2. 填入邮箱
3. 使用邮箱接码链接获取验证码，登录后继续
4. 复制浏览器回调地址，填入 CPA 平台提交

## SUB 授权

类似步骤，使用邮箱登录验证后完成授权。

# 六、邮箱接码与账号恢复

账号因 access_token 过期（通常10天）而失效时，可通过邮箱接码重新登录：

1. 复制卡密中的邮箱接码链接，在浏览器打开
2. 访问 OpenAI 官网：https://openai.com/zh-Hans-CN/
3. 使用邮箱登录，接码链接页面会刷新显示最新验证码
4. 填入验证码完成登录
